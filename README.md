# Vellorix — Eco-conscious Furniture Website

A responsive, multi-page Bootstrap 5 website concept for Vellorix.

## Pages
- `index.html` — Home
- `materials.html` — Materials
- `products.html` — Products and indicative INR prices
- `research.html` — Design and sustainability approach
- `staff.html` — Illustrative team profiles
- `locations.html` — Sonipat map and 10 proposed distributor markets
- `reach-us.html` — Contact form concept

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Built with
- HTML5
- Bootstrap 5.3.3 via CDN
- Internal CSS in every HTML page
- Responsive image URLs from Unsplash
- Google Maps embed centered on Subhash Chowk, Sonipat, Haryana

## Before publishing
This is a portfolio/demo concept. Product prices are illustrative; team profiles and distributor locations are proposed examples; contact details are placeholders. Verify all details, image usage/licensing, product specifications, and actual distributor availability before publishing. The contact form is front-end only and must be connected to a backend or form service to receive enquiries.
